# Qualixto `.github`

Organisation profile and default community health files for [Qualixto](https://qualixto.com) repositories. Any Qualixto repository without its own version of these files inherits them.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public organisation profile at [github.com/Qualixto](https://github.com/Qualixto) |
| `pull_request_template.md` | Default pull request description |
| `ISSUE_TEMPLATE/` | Bug and feature issue forms |
| `CONTRIBUTING.md` | Workflow, commit conventions and Definition of Done |
| `SECURITY.md` | How to report a vulnerability |
